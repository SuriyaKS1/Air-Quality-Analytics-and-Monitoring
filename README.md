# Air Quality Analytics & Monitoring Dashboard

## Project Overview

This project focuses on analyzing historical and live air-quality monitoring data using MySQL and Microsoft Power BI. It combines approximately 3,700 historical records with 852 live monitoring records to explore pollutant concentrations, identify location-wise pollution patterns, analyze temporal trends, and monitor data freshness.

The project follows an end-to-end data analytics workflow, covering data ingestion, database management, data cleaning, SQL analysis, and interactive Power BI dashboard development.

## Project Objectives

- Analyze historical and live air-quality monitoring data.
- Explore pollutant measurements such as PM2.5 and PM10, where available.
- Compare pollution measurements across cities and monitoring stations.
- Identify locations with comparatively higher pollutant levels.
- Analyze historical and recent measurement trends.
- Monitor sensor data freshness and measurement age.
- Develop interactive dashboards for air-quality analysis.

## Project Datasets

**Dataset 1 – Historical Air Quality Data**
- Approximately 3,700 records.
- Used for historical pollution analysis and trend exploration.
- Supports location-wise and pollutant-wise comparisons.

**Dataset 2 – Live Air Quality Monitoring Data**
- 852 imported records.
- Includes monitoring station, sensor, pollutant, geographic, timestamp, and data freshness information.
- Used to explore recent monitoring measurements and data availability.

**Total dataset coverage:** Approximately 4,552 records across both datasets, subject to overlap and duplicate validation.

## Project Workflow

### 1. Data Collection and Import
- Collected historical air-quality records.
- Retrieved live monitoring data.
- Imported datasets into MySQL.
- Organized data using staging and permanent tables.

### 2. Data Cleaning and Validation
- Checked missing values.
- Identified duplicate records.
- Validated pollutant measurements.
- Checked geographic coordinates and timestamps.
- Examined data freshness and measurement age.

### 3. SQL Exploratory Data Analysis
- Calculated average, minimum, and maximum pollutant measurements.
- Compared pollution levels across cities and monitoring stations.
- Analyzed daily and hourly measurement trends.
- Identified higher pollutant measurements.
- Evaluated live data freshness.

### 4. Power BI Dashboard Development
- Connected MySQL databases to Power BI.
- Prepared datasets using Power Query.
- Created DAX measures and KPI cards.
- Developed interactive charts, maps, and filters.
